# 경성야록 게임·힌트 위치 목록

총 13개: 1층 역사 퀴즈 6개와 시계 퍼즐 1개, 자료실 2개, 암실 1개, 건조방 3개. 난이도는 상·중·하로 표시합니다. 모든 게임은 현장에서 직접 조사해야 풀 수 있고, 오답은 진행을 잃지 않고 재시도할 수 있습니다.

| 방 | 게임 | 난이도 | 실제 조사 위치 |
|---|---|---|---|
| 1층 식자실 | 뒤섞인 연도 | 하 | 벽의 달력 |
| 1층 식자실 | 자정에 돌아오는 식자공 | 중 | 멈춘 괘종시계 |
| 1층 식자실 | 서랍 속 세 장의 종이 | 하 | 테이블 아래 24번 서랍 |
| 1층 식자실 | 먹칠된 이름 | 중 | 테이블 위 교정지 |
| 1층 식자실 | 빛나는 박람회의 그림자 | 중 | 뒤쪽 캐비닛 옆 벽의 조선박람회 포스터 |
| 1층 식자실 | 지워진 역할표 | 중 | 뒤쪽 철제 캐비닛 세 번째 서랍 안의 역할표 |

| 사진 건조방 | 신문과 시 | 하 | 초록 집게 사진 ① |

| 사진 건조방 | 마지막 지면의 판단 | 상 | 초록 집게 사진 ③ |

시계는 시·분 바늘을 직접 조작하는 창작 공포 퍼즐입니다. 역사적 사건이나 실제 인물의 기록이 아닙니다. 다른 문항은 경성야록의 기사·문학 및 교과 연계 자료를 해석하는 문제입니다.

## 힌트가 있는 위치

- 각 게임 물건의 조사창: 문제를 풀 수 있는 짧은 단서와 순서대로 공개하는 3단계 힌트.
- 캐비닛 세 번째 서랍: 서랍을 열어야 역할표가 나타납니다. 발견 후 소지품에도 역할 기록이 남습니다.
- PC ‘진행 안내’ / 모바일 ‘플레이 안내 → 방별 퍼즐·힌트 보기’: 남은 게임의 위치·난이도·힌트. 여기에서는 게임을 풀 수 없습니다.
- 수첩: 한 번 시도한 문제의 단서와 방별 완료 기록.
- 거울 활자판: 달력 위치 안내.
- 다른 잠긴 서랍: 24번 서랍 위치 안내.
- 테이블·활자 조판 홈·인쇄 롤러: 교정지 위치 안내.
- 안경·앞치마·큐브: 캐비닛 역할표 위치 안내.
- 활자 보관장·활자 색인표·라디오: 복도 책 위치 안내.
- 기존 검열 포스터: 박람회 포스터 위치 안내.
- 자료실의 보조 메모: 선반의 우리말 기록 위치 안내.
- 자료실·암실 사이 커튼: 해당 방의 남은 게임 안내.
- 사진 건조방의 안내 쪽지: 남은 사진 게임 안내.

## 철문·열쇠 진행

1. 출구 철문에는 1층 게임 7개와 열쇠 획득의 체크리스트만 보입니다. 퀴즈·힌트 토글·원격 실행 버튼은 없습니다.
2. 머리카락 엉킨 열쇠는 1층 왼쪽 선반에서 직접 챙깁니다.
3. 게임 7개 완료와 열쇠 획득이 모두 체크되면 철문이 자동으로 열립니다.
4. 안쪽 책상의 종이를 조사한 뒤 ‘열쇠 올려놓기’를 실행해야 지하실 문이 자동으로 열립니다. 종이를 읽는 것만으로는 열리지 않습니다.
5. 사용한 열쇠는 소지품에서 빠지고 종이 위에 실제 소품으로 남습니다.

## 공포·음향

- 철문 안 방의 양옆 벽·정면 벽·천장: 검은 손 그림자 24개가 서서히 흔들리고 뻗어 나옵니다. 조사와 이동을 가리지 않습니다.
- 철문 안 방: 제공된 크리처 음원을 낮은 음량으로 반복 재생합니다. 방을 벗어나면 멈추고, 음소거·탭 숨김·시간 초과 종료에서도 정지합니다.
- 무작위 귀신 팝업: 기존 3종 음원의 조용한 무작위 재생과 페이드 효과 유지.
