# 독립 모바일 확장 모듈

`mobile-expansion.js`는 독립 퍼즐 모듈입니다. 3D 자료실과 암실 연결은 별도 `archive-space.js`, `darkroom-space.js`, `archive-bootstrap.js`에서 관리합니다.
자료실 → 암실 → 윤전기실의 단계별 퍼즐, 다음 방 잠금, 힌트, 보상 숫자, 터치용 기본 UI를 포함합니다.
독립 퍼즐 모듈을 공유 3D 공간에서 연결하며, PC와 모바일이 같은 진행 규칙을 사용합니다.

```html
<link rel="stylesheet" href="room-puzzles.css">
<script src="room-puzzles.js"></script>
<script src="mobile-expansion.js"></script>
<div id="mobile-extra"></div>
```

```js
const expansion = new GyeongMobileExpansion.Expansion({
  // 기존 타이머가 가진 남은 초를 반환해야 합니다. 새 10분을 시작하지 않습니다.
  getRemainingSeconds: () => Math.max(0, 600 - (performance.now() - game.playTimer.startedAt) / 1000),
  onRoomChange: ({ room }) => {
    // room.id: archive, darkroom, press
    // 여기에서 별도의 모바일 3D 방과 이동 경계를 생성합니다.
  },
  onComplete: () => game.rewardCardRenderer.startSequence(),
  onTimeout: () => { /* 원본 타이머의 종료 화면 유지 */ }
});
// 공유 구간을 완료했고 기존 타이머가 시작된 상태에서 호출합니다.
expansion.start(document.getElementById('mobile-extra'));
// 연결을 해제할 때 expansion.destroy();
```

퍼즐 파일 자체는 단계 진행과 UI만 관리합니다. 현재 자료실의 지형·계단 높이·충돌·문 애니메이션은 별도 `archive-space.js`에 구현되어 있습니다.
`onRoomChange`에 공간 생성 코드를 연결하는 방식으로 이 모듈만 계속 개발할 수 있습니다.
실제 연결 때에는 원본 입력을 잠시 멈추고 기존 타이머·귀신 컨트롤러는 계속 갱신해야 합니다.
PC와 모바일 모두 기존 식자실의 24번 서랍을 풀면 오른쪽 벽의 자료실 문을 열 수 있습니다. 기존 복도 끝 철문은 원래 엔딩으로 연결됩니다. 암실까지 3D로 연결되며 추가 윤전기실의 3D 연결은 후속 작업입니다.
최종 호외 종류는 원본 퍼즐 상태에 따라 결정됩니다. 추가 퍼즐 보상과 새로운 호외 디자인 연결도 후속 작업입니다.

검증: `node mobile-expansion/test.cjs`

## 독립 미리보기

`preview.html`을 열면 원본 게임 없이 세 방의 퍼즐과 단계 이동을 체험할 수 있습니다.
PC에서도 미리보기를 허용하며, 휴대폰 크기에 맞춰 표시합니다.
미리보기의 시작 버튼에서 전체 10분을 시작하고, 방을 옮길 때는 시간을 초기화하지 않습니다.
이 화면은 퍼즐 모듈 확인용으로, 아직 3D 공간·조이스틱·귀신·호외 이미지가 포함되지 않았습니다.

로컬 서버로 열려면 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤
브라우저에서 `/mobile-expansion/preview.html` 경로를 여세요.
기존 게임은 `/sikjasil/` 경로에서 확인합니다.
배포 환경에서는 같은 미리보기 경로를 사용하지만, 새 폴더를 GitHub에 올린 뒤 배포해야 접근할 수 있습니다.

## 3D 자료실

`archive-preview.html`은 기존 식자실을 모바일 조작 모드로 열어 3D 자료실을 확인하는 페이지입니다.
이 페이지에서는 PC도 마우스로 왼쪽 조이스틱을 끌고 화면을 드래그하여 모바일 조작을 체험할 수 있습니다.
일반 `/sikjasil/`에서 PC와 모바일 모두 자료실·암실을 공유합니다. PC는 WASD 이동·마우스 시점·E 조사, 모바일은 조이스틱·터치 시점·픽업 버튼을 사용합니다.

경로: 식자실 오른쪽 벽 문 → 좁고 낡은 지하 계단 20단 → 아치형 천장의 자료실.
자료실 바닥은 메인보다 3.6m 아래이고 공간은 14×7m입니다.
서가·문서 더미·상자·중앙 기록 책상·낡은 벽·어두운 조명을 모델링했습니다.
24번 서랍 암호(2358)를 먼저 풀고 자료실 입구를 조사하여 문을 열어 주세요.
아래로 내려가 초록 날짜 메모(서가·책상)를 읽고 중앙 책상을 조사하세요. 천공 먹지 얻기 → 먹지 한 번에 맞추기 → 날짜 1124 입력(또는 단서 날짜 넣기) → 스탬프 찍기 순서로 암실 철문 열쇠를 얻습니다. 완료 안내의 버튼으로 조사창을 닫고 자료실 끝 暗室 표지·검은 커튼을 조사하면 다음 암실 문을 열 수 있습니다.
같은 계단을 올라 식자실로 돌아올 수 있습니다. 타이머는 계속 진행하며 초기화되지 않습니다.

`archive-space.js`는 주입받은 Three.js 생성자를 사용하며 추가 CDN이나 라이브러리 설치가 필요 없습니다.
`archive-bootstrap.js`만 호스트 게임의 `sikjasil-ready` 이벤트에 연결합니다.
`game.sceneAPI`에는 공간 생성에 필요한 생성자가 있고, `game.mobileArchive`에서 자료실 진행을 확인할 수 있습니다.
`darkroom-space.js`는 자료실 끝 검은 커튼 뒤에 7×6m 인화실과 7×6m 사진 건조실을 연결합니다. 편집실의 날짜 인장을 해결하면 철문 열쇠로 첫 커튼 안쪽의 철문을 열 수 있습니다. 인화 작업대에서 필름 세척 → 붉은 등 → 현상액 → 정착액 순서를 해결하면 숫자 14를 얻고 두 번째 커튼이 열립니다.
낡은 확대기·약품병·인화 트레이·작업대와 천장/벽의 사진 63장을 배치했습니다. 기존 여섯 귀신 이미지가 사진에 나타나며, 건조실의 붉은 조명은 점멸합니다. 기존 귀신 출현 일정과 전체 10분 타이머는 그대로 유지됩니다.
`game.mobileDarkroom`에서 커튼, 현상 퍼즐, 조명 상태를 확인할 수 있습니다. 추가 윤전기실의 3D 공간은 아직 만들지 않았습니다.

검증: `node mobile-expansion/archive-route.test.cjs` 및 모바일에서 서랍 → 문 → 계단 → 자료실 기록 → 커튼 → 인화 퍼즐 → 커튼 → 붉은 사진실 → 계단 복귀 플레이.
브라우저 검증: `PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright node tests/archive-space-smoke.cjs` (저장소 루트의 정적 서버가 기본 8001 포트에서 실행 중이어야 합니다. `GAME_TEST_URL`로 변경 가능).

PC 전체 동선 검증: 위 브라우저 검증 명령에 `GAME_TEST_PLATFORM=desktop`을 추가합니다.

## 공유 공간의 새 퍼즐

- 지하 자료실(쉬움): 먹지 획득 → 한 번에 격자 맞추기 → 11월 24일 확인 → 날짜 1124 입력/단서 날짜 넣기 → 철문 열쇠. 방향·회전·자리별 증감 조작을 없앴습니다. 풀이와 다음 장소 안내는 초록 메모의 펼침 안내에서 바로 볼 수 있습니다. 완료 시 조명 암전 효과, 타자기 소리·롤러 회전·협박문 출력이 재생됩니다.
- 사진 암실(매우 어려움): 필름 세척 → 붉은 안전등 확인 → 현상액 침지 → 정착액 투입. 인화지를 트레이로 드래그하거나 처리 버튼을 누릅니다. 현상액 침지 후 3초 이상 기다려 얼굴이 드러난 뒤 정착해야 합니다. 너무 이른 정착, 잘못된 순서 또는 일반 전등은 종이를 태우고 진행을 초기화합니다. 약품을 다시 채우면 재시도할 수 있습니다. 성공하면 윤전기와 붉은 14가 드러나며 그림자와 파열음, 일시적 암전 효과가 재생됩니다.
- 실패해도 전체 10분은 초기화되지 않습니다. 소품 획득과 성공 상태는 조사 화면을 닫았다 열어도 유지됩니다. 기존 6회 무작위 귀신 출현에 더해 퍼즐 완료 시 별도의 고정 연출이 재생됩니다. 암전은 약 4.5초 후 해제되어 다음 공간 탐색을 이어갈 수 있습니다.
- 상태 검증: `node mobile-expansion/room-puzzles.test.cjs`. PC/모바일 전체 경로 검증은 `tests/archive-space-smoke.cjs`를 두 입력 모드로 실행합니다.

무작위 귀신 출현은 메인·계단·자료실/편집실·암실·사진실의 현재 플레이어 위치에 맞춰 배치됩니다. 추가 공간에서는 천장·바닥·벽·코너 중 무작위 위치를 선택하며 페이드인 약 0.45초, 페이드아웃 약 0.8초를 사용합니다. 방을 바꾸어도 기존 6회 일정과 귀신 6종은 다시 생성하지 않습니다. 검증: `node --test tests/ghost-plan.test.cjs`.

## 추가 긴장감 연출

`tension-director.js`를 두 플랫폼에 공통 연결했습니다. 뒤쪽의 위치 음향 발소리가 5m에서 1m까지 가까워지고, 뒤를 돌아보면 멎습니다. 다시 소품/작업대를 조사하면 이어집니다. 음소거 설정을 따르며 귀신/암전 연출 중에는 겹쳐 재생하지 않습니다.
사진 건조실에서 처음 본 사진은 유지되지만, 시선을 1.2초 이상 돌렸다가 다시 보면 일부 사진 속 인물의 방향과 위치가 변합니다. 최소 12초 간격으로 한 장씩 변하며, 종이·집게·빨랫줄은 유지됩니다. 두 요소는 퍼즐·이동·10분 타이머·귀신 6회 일정에 영향을 주지 않습니다.
검증: `node mobile-expansion/tension-director.test.cjs`와 두 플랫폼의 `tests/archive-space-smoke.cjs`. 날짜 스탬프 숫자 입력과 이른 정착 실패는 `tests/puzzle-ui-regression.cjs`에서 확인합니다.

모바일의 확장 소지품 목록은 가로 화면에서는 두 조작 영역 사이에, 좁은 화면에서는 상단에 배치하며 긴 목록은 스크롤됩니다. `tests/mobile-inventory-layout.cjs`에서 844×390, 390×844, 667×375 화면을 검증합니다.

새 퍼즐에는 초록 메모의 첫 힌트가 항상 표시됩니다. “다음 힌트 보기”를 누르면 정렬 좌표·스탬프 1124, 약품 순서·3초 대기·실패 복구 방법까지 단계별로 표시되며, 조사 화면을 다시 열어도 유지됩니다. 검열문·서랍의 먹지·서류함·암실 트레이를 초록 테두리로 표시하고 암실 벽에 초록 현상사 메모를 배치했습니다. 표시 테두리는 조사 광선을 막지 않습니다.

퍼즐 안내 색상은 기존 식자실과 확장 공간 모두 초록 계열(#39c85a)로 통일했습니다. 소품 조사 강조·테두리·퍼즐 버튼·힌트가 같은 색상을 사용합니다. 암실의 붉은 안전등과 혈흔 등 공포 소품의 색상은 유지됩니다.

귀신 6회에는 천장 추락·바닥 상승·좌우 횡단·화면 전체 확대·코너 대각선 이동·가까운 모습에서 멀어지며 소멸의 서로 다른 6개 트랙을 배정합니다. 화면 중앙에서 멈추는 공통 연출과 겹쳐 보이던 정적인 월드 귀신 복사본을 제거했습니다. 시작/일시정지·퍼즐 조사·수첩·호외 인쇄/카드·엔딩에서는 무작위 귀신을 보류하고, 이미 나타난 귀신도 즉시 숨깁니다. 아직 출현하지 않은 예약은 탐색 복귀 후 간격을 두고 재개하며 총 10분은 연장하지 않습니다. 암실 퍼즐 완료의 암전·파열음은 유지하지만 퀴즈 화면에 귀신 이미지는 띄우지 않습니다.

## 자료실 도움말·화면 검증

`node tests/archive-puzzle-help.cjs`는 1280×720, 953×600, 844×390, 390×844 화면에서 조사 제목·닫기 버튼의 화면 내 배치, 먹지 획득·자동 정렬·날짜 오답 재시도·단서 날짜 입력·완료 안내·다음 방 이동을 검증합니다. 조사창 내용은 내부 스크롤로 읽고 닫기 버튼은 고정 영역에서 사용합니다.

`GAME_TEST_URL=http://127.0.0.1:8000 node tests/archive-game-flow.cjs`는 실제 3D 게임에서 PC·모바일의 자료실 풀이 → 열쇠 획득 → 완료 안내로 조사창 닫기 → 검은 커튼 열기 → 암실 단계 전환을 확인합니다. 관찰 위치만 소품 앞으로 옮기며 정답·소지품·완료 상태는 실제 조사 UI를 통해 얻습니다.

## 사진 건조방 — 사라진 사람 찾기

암실 현상을 마치고 두 번째 검은 커튼을 열면 사진 건조방을 계속 탐색할 수 있습니다. 입구의 초록 메모와 안내문을 읽고 왼쪽 벽의 초록 집게 사진 ①(입구) → ②(가운데) → ③(안쪽)를 조사하세요. 확대 화면에서 세 사진에 공통으로 등장하는 검은 모자 인물을 선택합니다. 틀려도 이전 진행은 유지되고, 초록 힌트를 누르면 모자 인물이 강조됩니다. 세 장의 조사 순서는 자유롭습니다.

완료하면 사진 속 모자 인물이 사라지고 윤전기실 열쇠를 얻습니다. 다음 시즌 「새벽의 윤전기: 아직 인쇄되지 않은 실종자」 예고를 읽은 뒤 버튼을 눌러 퍼즐 창을 닫고 탐색으로 돌아갑니다. 퍼즐 완료·건조방 커튼 열기·기존 복도 철문 열기는 게임 종료를 호출하지 않습니다. 기존 전체 10분 타이머는 그대로 적용됩니다. 윤전기실 열쇠는 후속 퍼즐을 위한 소지품으로, 이 변경에서 새로운 윤전기실 공간을 만들지는 않습니다.

검증: `node --test tests/missing-person.test.cjs`, 정적 서버 실행 후 `GAME_TEST_URL=http://127.0.0.1:8000 node tests/missing-person-game.cjs`. 브라우저 검증은 PC·모바일의 자료실·현상·건조방 흐름, 오답·힌트·세 사진 완료·예고·창 닫기와 탐색 유지, 기존 철문 엔딩 진입 방지를 확인합니다. 관찰 위치만 소품 앞으로 옮기며 정답이나 완료 상태를 강제하지 않습니다.

모바일 사진 퍼즐은 인물 이름 표기, 48px 이상 터치 버튼, 세로·가로 화면 배치와 터치 안내를 제공합니다. `node tests/missing-person-touch.cjs`로 390×844, 360×640, 844×390, 667×375 화면의 터치 선택·힌트·완료 버튼·스크롤을 확인합니다. `GAME_TEST_PLATFORM=mobile GAME_TEST_URL=http://127.0.0.1:8000 node tests/missing-person-game.cjs`는 실제 게임 흐름의 버튼을 터치로 검증합니다. 실제 iOS Safari·Android 기기의 음향·성능은 별도 확인이 필요합니다.

사진 건조방에 처음 들어오면 초록 단서의 위치와 풀이 안내가 조사창으로 한 번 표시됩니다. 안내 확인 후 탐색으로 복귀하며 재입장에는 반복하지 않습니다. 사진사의 메모는 입구 쪽 왼쪽 벽의 첫 퀴즈 사진 옆에 붙어 있고 정방향으로 읽힙니다. 퀴즈 사진 프레임은 주변 사진과 같은 0.48×0.68 크기이며, 세로 인화지와 초록 집게를 사용합니다. 현재 임시 인물 이미지는 `darkroom-space.js`의 `missingPhotoTexture`에서 생성하며 이후 세 사진 교체 지점으로 사용할 수 있습니다.

사용자가 올린 `game.zip`의 이미지 8장 중 `_01`, `_03`, `_06` 사진을 사진방 퀴즈에 적용했습니다. 원본 PNG는 `assets/missing-person/photo-1.png`부터 `photo-3.png`까지 보관합니다. 실제 사진의 왼쪽 검은 모자, 가운데 안경, 오른쪽 납작 모자를 터치/클릭해서 선택합니다. 원본 비율을 유지하며 확대 화면과 3D 인화지에 “이 사진은 ai생성 이미지 입니다.”라고 표시합니다.

## 현재 사진방 퍼즐 — 사진 속 달라진 흔적

위의 사라진 사람 찾기는 원본/건조 사진 비교 퍼즐로 교체되었습니다. 초록 집게 사진 세 장을 조사하고 각 사진의 원본과 건조본에서 차이 한 곳을 찾습니다. 사진 1: 오른쪽 위 압수 도장, 사진 2: 왼쪽 아래 24, 사진 3: 위쪽 가운데 ×. 달라진 흔적은 게임 화면에만 덧붙이며 사용자가 제공한 원본 PNG는 수정하지 않습니다. 초록 힌트를 즉시 볼 수 있고 오답에도 완료한 사진은 유지됩니다. PC는 나란히, 모바일 세로 화면은 위아래로 비교합니다. 세 장을 완료하면 열쇠·다음 시즌 예고를 확인하고 탐색으로 돌아갑니다. 기존 타이머와 방 열기 시 탐색 유지 규칙은 동일합니다. AI 생성 이미지 참고 문구도 유지합니다.

## 最終 사진 뒷면 엔딩

틀린그림 세 장을 모두 찾으면 “모든 퍼즐을 해결했습니다 / 게임이 종료되었습니다”를 표시하고 마지막으로 푼 사진을 뒤집습니다. 사진 뒷면에는 다음 시즌 「새벽의 윤전기」의 공포 예고를 남깁니다. 전체 타이머, 확장 퍼즐 타이머, 귀신 연출과 이동을 멈추고 예고 확인 버튼을 누르면 종료 안내 화면에 머뭅니다. 재시작은 페이지 새로고침으로 합니다. 방 입장과 기존 철문 열기 자체는 여전히 게임을 종료하지 않습니다. 이전의 완료 후 자유 탐색 안내는 이 최종 엔딩으로 대체되었습니다.

최종 성공 엔딩은 식자실 24번 서랍 → 자료실 날짜 스탬프 → 암실 현상 → 사진방의 차이 세 곳을 모두 완료한 경우에만 시작합니다. 사진 세 장만 완료한 상태에서는 남은 필수 퍼즐 안내를 보여주며 종료하지 않습니다. 모든 필수 조건이 충족되면 마지막으로 해결한 사진이 뒤집히고 사진 뒷면의 다음 시즌 공포 예고와 게임 종료 안내를 표시합니다.

## 모바일 탐색 화면 간소화

모바일 상단에는 남은 시간만 표시합니다. 위치/날짜, 큰 목표 안내, 단서 거리 표식, 상시 소지품 목록과 하단 PC 키 설명은 숨기고, 왼쪽 아래 ‘플레이 안내’ 버튼으로 조작법·현재 목표·소지품을 확인합니다. 안내를 닫으면 이동/조사가 복귀하며 타이머는 안내 중에도 계속 흐릅니다. 모바일 사진방의 자동 입장 안내창은 생략하고 현재 목표는 안내 버튼에서 확인합니다. 실제 사진 조사와 퍼즐 화면은 그대로 사용합니다. PC 화면은 기존 표시를 유지합니다.

검증: 정적 서버 실행 후 `GAME_TEST_URL=http://127.0.0.1:8000 node tests/mobile-guide.cjs`로 모바일 화면 크기 4종의 HUD, 타이머, 안내 버튼과 닫기·복귀, 사진방 안내의 수동 열기를 확인합니다.

## 모바일 가까운 초록 단서 조사 보조

모바일은 작은 물체를 화면 중앙에 정확히 맞추지 않아도, 전방의 가까운 단서(물체 표면 기준 약 2.6m)를 조사 대상으로 보조 선택합니다. 가려진/숨겨진 단서와 플레이어 뒤쪽 단서는 제외합니다. 같은 위치에 교정지와 서랍처럼 여러 단서가 있으면 ‘픽업·조사’를 누른 뒤 가까운 초록 단서 목록에서 원하는 퍼즐을 고릅니다. 목록을 닫으면 탐색이 복귀합니다. PC 조사 방식은 그대로 유지합니다.

검증: 정적 서버 실행 후 `GAME_TEST_URL=http://127.0.0.1:8000 node tests/mobile-pickup-assist.cjs`. 실제 서랍·자료실·암실의 빗나간 조준과 조사 창 열기, 후방·벽·거리 차단을 확인합니다.

## 모바일 전체 실제 이동 플레이 검증

`GAME_TEST_URL=http://127.0.0.1:8000 node tests/mobile-full-playthrough.cjs`는 모바일 브라우저 에뮬레이션에서 실제 터치 조이스틱으로 이동하여 서랍 → 자료실 문 → 계단 → 자료실 → 암실 → 사진방 → 최종 엔딩을 검증합니다. 위치 이동·퍼즐 정답 상태·소지품을 강제로 설정하지 않습니다. 시점 방향은 자동화가 조절하며, 이동은 터치 입력과 실제 충돌 처리를 거칩니다. 각 조사 팝업을 세로 390×844 / 가로 844×390으로 회전해 화면 내 배치와 가로 잘림을 검사합니다. 마지막 사진 뒷면의 회전 완료, 공포 예고, 타이머 중지, 게임 종료 문구와 JavaScript 오류·누락된 로컬 리소스도 확인합니다. 그래픽 해상도만 소프트웨어 렌더링 테스트용으로 낮춥니다. 실제 iOS/Android 기기의 성능·음향·브라우저별 동작은 기기에서 별도 확인합니다.
