# 경성야록 京城野錄

> 밤이 깊어지면 잊힌 사건이 깨어나리라 — 신문 한 줄에서 시작되는 경성의 기이한 이야기

1930년대 동아일보 지면을 본뜬 미스터리 아카이브 웹사이트입니다.
실제 신문 기사 한 줄에서 출발해, 그날의 사건을 지면 · 장치 · 소리로 다시 펼쳐 보입니다.

## 여는 법

`index.html` 을 브라우저로 열면 됩니다. (설치할 것 없음)

## 알려 두는 것

- 그림 중 「재현 그림」 표시가 있는 것은 AI(미드저니)로 새로 그린 것이며 실제 사진이 아닙니다.
- 「편집국 재구성」 표시가 있는 글은 기록에 없는 부분을 편집국이 지어 쓴 것입니다. 기사 제목 · 부제 · 날짜는 확인된 기록만 썼습니다.
- 독자 호외는 이용자가 지어 내는 창작물이며 실제 사건이 아닙니다.
- 새로고침하거나 창을 새로 열면 진행 상황이 처음으로 돌아갑니다.

## 식자실 게임 — 모바일 / PC

### 역사 기록 복원 게임

현재 `/sikjasil/`은 공포·미스터리 분위기 속에서 역사 기록을 복원하는 공통 PC/모바일 게임입니다. 난이도는 **상·중·하**로 표시하며, 1층 식자실 7개(역사 퀴즈 6개·시계 퍼즐 1개) → 지하 자료실 2개 → 암실 1개 → 사진 건조방 3개의 필수 퀴즈를 방마다 모두 해결해야 다음 문이 열립니다. 1층 철문 안 책상 종이에 머리카락 엉킨 열쇠를 올려놓으면 지하실 문이 자동으로 열립니다. 실제 계단은 오른쪽 자료실 문에 있습니다.

1층 문제를 완료하고 머리카락 엉킨 열쇠를 챙기면 철문이 자동으로 열립니다. 철문 안의 낡은 테이블 위 종이를 조사하고 열쇠를 올려놓으면 오른쪽 자료실 문이 열립니다. 뒤쪽 왼편 철제 캐비닛은 세 번째 서랍을 열어 역할표를 발견하고, 복도 바닥의 낡은 하드커버 책은 가까이 겨냥할 때만 제목이 표시됩니다. 정답 후 문제창에는 짧은 해설과 다음 행동을 표시합니다.

모든 문제는 게임 안 단서·3단계 힌트로 풀 수 있고 오답은 다시 시도할 수 있습니다. 진행 안내·수첩에서 남은 기록을 확인합니다. 출구 철문은 완료 여부 체크리스트만 표시하며, 1층 필수 게임과 열쇠 획득이 모두 체크되면 자동으로 열립니다. 자세한 위치·힌트는 진행 안내에서 확인하며, 실제 게임은 해당 물건에서 풉니다. 탐색 중 목표는 짧게 표시하고 자세한 설명은 조사할 때만 열립니다. 초록색 공간 힌트는 평소 희미하며 가까이 겨냥할 때 진해집니다. 기존 공포 연출·음향·10분 제한은 유지됩니다. 새로고침하면 진행이 초기화됩니다.

문항·방별 진행은 `mobile-expansion/history-game.js`, 시선 반응 힌트는 `mobile-expansion/hint-focus.js`에 있습니다. 검증은 정적 서버를 실행한 뒤 `node --test tests/history-game.test.cjs tests/ghost-plan.test.cjs tests/missing-person.test.cjs`, `node tests/history-game-smoke.cjs`로 실행합니다. 새 브라우저 테스트는 PC/모바일의 방 잠금·오답 재시도·단서·힌트·출구 안내·팝업 범위·힌트 밝기·엔딩을 검사하고, 모바일은 터치 조이스틱으로 방 사이를 이동합니다. 테스트용 그래픽 해상도와 관찰 방향은 조정합니다.

실제 휴대전화의 음향·설치·성능은 별도로 확인해야 합니다.

식자실은 메인 지면에 흩어진 물건 네 개를 모은 뒤 하단 판권의 거꾸로 된 `版` 버튼으로 들어가거나
`sikjasil/index.html`을 직접 열 수 있습니다. 모바일에서는 왼쪽 하단 원형 조이스틱(기울기에 따라 이동 속도 조절)과
화면 드래그로 이동·시점을 조작하고 오른쪽 하단 픽업·조사 버튼 및 보조 버튼으로 수첩, 손전등,
웅크리기, 집중, 음향을 조작합니다. 가로 화면을 권장합니다. PC는 기존 키보드·마우스 조작을 사용합니다.

터치 입력은 `sikjasil/assets/mobile-controls.js`, 모바일 화면 조정은
`mobile-controls.css`에서 관리합니다. `game-classic.js`의 `sikjasil-ready` 이벤트가
게임 초기화 완료 후 입력 어댑터에 게임 인스턴스를 전달합니다.

개발 중에는 저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행합니다.
Playwright와 Chromium이 설치된 환경에서 `node tests/game-input-smoke.cjs`로
모바일 이동·시점·조사·수첩·게임 진입/복귀와 PC 마우스 잠금을 검증할 수 있습니다.
필요하면 `PLAYWRIGHT_MODULE`에 설치된 Playwright 모듈 경로,
`GAME_TEST_URL`에 테스트 서버 주소를 지정합니다. 테스트는 `/usr/bin/chromium`을 사용합니다.
모바일 에뮬레이션 검증과 별도로 실제 iOS Safari / Android Chrome에서 터치·음향·성능을 확인해야 합니다.

## 무작위 귀신 연출 — 웹 / 모바일 공통

탐색 중 귀신 6종이 한 번씩, 총 6회 등장합니다. 매 플레이마다 등장 시간·귀신 순서·장소를 새로 정합니다.
장소 후보는 천장, 바닥, 코너, 캐비닛 뒤, 벽, 복도, 서랍, 철문 뒤이며, 이 중 여섯 곳을 중복 없이 선택합니다.
각 등장 시 실제 공간의 귀신과 화면으로 튀어나오는 투명 이미지 연출을 함께 표시합니다.
모바일·웹은 `assets/ghost-director.js`의 같은 스케줄과 이미지를 사용하며 화면 크기만 CSS로 조정합니다.

등장은 게임 시작 후 20초부터 9분 사이에 분산되며, 최소 20초 간격을 둡니다.

팝업 사운드는 업로드한 괴물 음원 3종 중 하나를 무작위로 재생합니다(중복 업로드는 제외). 기본 음량은 18%이며 전체 음량·음소거를 따릅니다. 팝업의 2.4초 안에서 시작 0.18초 페이드 인, 끝 0.45초 페이드 아웃을 적용하고, 조사·수첩·게임 종료로 팝업이 닫히면 짧게 페이드 아웃합니다. 팝업에 겹치던 기존 금속음·추가 비명은 제거했습니다. 음원은 정적 HTTP 서버 또는 GitHub Pages에서 로드합니다.

오디오 검증: `node --test tests/ghost-audio.test.cjs`, 정적 서버 실행 후 `node tests/ghost-audio-smoke.cjs`.
조사창·수첩에서도 시간이 흐르지만, 읽는 동안 무작위 귀신 팝업은 숨깁니다. 귀신 레이어는 터치·클릭·조사를 가로채지 않습니다.
호외 인쇄에 별도 귀신 팝업을 추가하지 않으며, 게임 종료·철문 엔딩에서는 무작위 등장을 멈춥니다.
일찍 엔딩에 도달하면 남은 예약은 취소합니다. 새로 시작하면 다시 6회로 초기화됩니다.

이미지는 `sikjasil/assets/ghosts/`에 보관하며, 더블클릭으로 여는 경우 `media-local-ghosts.js`가 같은 PNG를 제공합니다.
참고 이미지를 바탕으로 새로 생성한 귀신: 천장 원혼, 소복 그림자, 벽 속 식자공, 매달린 원혼, 활자장 노인, 먹물 속 비명.

검증: `node --test tests/ghost-plan.test.cjs`, `node tests/ghost-browser-smoke.cjs`.
브라우저 검증은 테스트 시계를 가속하여 웹·모바일 양쪽의 10분 동안 6회 등장과 종료를 확인합니다.

`node tests/ghost-visual-smoke.cjs`는 시간을 가속하지 않고 웹·모바일의 첫 팝업이 실제로 보이는지 확인합니다.
로컬 파일 열기가 허용된 브라우저에서는 `GHOST_TEST_FILE=1`로 더블클릭 경로도 확인할 수 있습니다.
관리형 클라우드 브라우저의 `file://` 열기는 정책으로 차단되어 런타임 검증하지 못했으며,
내장 이미지 매핑은 원본 PNG와 일치하는지 별도로 검증했습니다.

## 무료 모바일 테스트 앱 (PWA)

GitHub Pages의 `main` / 저장소 루트 배포를 그대로 사용합니다. HTTPS로 `/sikjasil/`을 열어 앱처럼 설치할 수 있습니다. 별도 서버·앱스토어 계정·APK 빌드가 필요 없습니다.

- Android Chrome: 게임의 ‘플레이 안내’ → ‘홈 화면에 앱 설치’, 또는 Chrome 메뉴 → 앱 설치/홈 화면에 추가.
- iPhone Safari: 게임 주소 열기 → 공유 → 홈 화면에 추가. 지원되는 버전에서는 ‘웹 앱으로 열기’를 사용합니다.
- 홈 화면 아이콘으로 실행하면 브라우저 주소창 없이 독립 화면으로 플레이합니다. 가로 화면을 권장하며 화면 방향 잠금 지원은 기기별로 다릅니다.
- 처음 실행할 때는 인터넷에 연결하세요. 캐시는 이미 요청한 게임 파일의 재사용을 돕지만 모든 음원·미방문 공간의 완전한 오프라인 실행을 보장하지 않습니다.
- 온라인에서는 최신 파일을 우선 요청합니다. 업데이트 확인은 앱을 완전히 닫고 인터넷에 연결한 상태로 다시 실행하세요. 서비스 워커 업데이트는 진행 중 게임을 강제 새로고침하지 않습니다.

설정: `sikjasil/manifest.webmanifest`, `sikjasil/pwa-install.js`, `game-pwa-sw.js`. 서비스 워커는 식자실 경로만 제어하며 나머지 신문 사이트의 페이지는 제어하지 않습니다.
검증: 정적 서버 실행 후 `GAME_TEST_URL=http://127.0.0.1:8000 node tests/pwa-smoke.cjs`. 실제 휴대폰의 설치·음향·성능은 기기에서 확인합니다.

퀴즈 정답 시 업로드된 `correct.mp3`를 재생합니다. 건조실 사진 3개를 모두 풀면 마지막 사진의 뒤집기 시작(기본 0.6초 대기)에 맞춰 `ending.mp3`를 한 번 재생합니다. 마지막 정답음은 엔딩음 시작 시 종료하며, 모두 전체 음량·음소거를 따릅니다.
정답·엔딩 음원 검증: 정적 서버 실행 후 `node tests/feedback-audio-smoke.cjs` (PC/모바일 정답·오답·중복 재생 방지·마지막 사진·음소거).

박람회 포스터는 사용자 제공 PDF를 낡고 채도가 낮은 종이 질감으로 편집해 캐비닛 옆 벽에 부착했습니다. 공중 제목판은 제거했으며, 실제 포스터를 겨냥해 클릭하거나 모바일 조사 버튼으로 퀴즈를 엽니다. 검증: `node tests/history-poster-smoke.cjs`.

괘종시계에는 난이도 중 「자정에 돌아오는 식자공」 퍼즐이 있습니다. 시·분 바늘을 조작해 자정을 넘긴 기록의 16분 전을 찾는 창작 공포 장치이며, 역사적 사건의 기록이 아닙니다. 오답 재시도·초기화·3단계 힌트·정답음을 제공하고, 1층 출구의 필수 완료 조건에 포함합니다. 검증: `node tests/clock-puzzle-smoke.cjs`.

철문 체크리스트: 1층 게임 7개 + 왼쪽 선반의 머리카락 엉킨 열쇠 획득. 철문은 모든 조건 완료 시 자동 개방합니다. 안쪽 종이를 읽는 것만으로는 지하실 문이 열리지 않으며, 열쇠를 실제로 올려놓아야 합니다. 사용한 열쇠는 소지품에서 빠지고 종이 위의 소품으로 남습니다.

전체 [게임·힌트 위치 목록](docs/game-and-hint-locations.ko.md)을 제공합니다. 철문 안 방의 양옆·정면 벽과 천장에는 손 그림자 24개가 움직이며, 제공된 크리처 음원을 낮은 음량으로 반복합니다. 배경음은 그 방 안에서만 재생되고 퇴실·음소거·탭 숨김·시간 초과 시 정지합니다. 검증: `node tests/exit-horror-smoke.cjs`.
