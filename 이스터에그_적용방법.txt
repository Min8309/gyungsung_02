경성야록 · 식자실 게임 적용 및 배포 방법 (2026-10-16)
========================================================

현재 게임은 PC와 모바일에서 플레이할 수 있습니다. 14개 게임을 방별로 풀며 진행하고, 게임 제한 시간은 10분입니다.

1. 신문 사이트에 통합할 때
  사이트 루트에 아래 항목을 함께 배포해야 합니다.
    index.html 및 기존 신문 사이트 파일
    sikjasil-egg.js
    sikjasil/             게임·음원·기본 이미지
    mobile-expansion/     필수 공간·역사 퍼즐·UI 및 추가 이미지
    game-pwa-sw.js        홈 화면 설치용 서비스 워커
  메인 index.html의 </body> 바로 앞에는 다음 태그가 필요합니다.
    <script src="sikjasil-egg.js"></script>
  기존 페이지에 이미 있으면 중복 추가하지 마세요.

  주의: 소스의 sikjasil/ 폴더만 복사하면 필수 ../mobile-expansion/ 참조가 끊깁니다.
  두 폴더는 같은 상위 경로에 나란히 있어야 합니다.

2. 게임만 독립 배포할 때
  저장소 루트에서 실행합니다.
    python3 tools/package-sikjasil.py --output /tmp/sikjasil-standalone.zip
  출력 위치는 원하는 새 ZIP 경로로 바꿀 수 있습니다. 기존 파일을 덮어쓰지 않습니다.
  ZIP을 새 폴더에 풀고, 풀린 모든 파일을 정적 웹 서버에 올리세요.
  패키지에는 필수 mobile-expansion/과 서비스 워커가 포함되며 경로가 독립 배포용으로 바뀝니다.
  ZIP 안의 index.html이 게임 시작 페이지입니다. 소스 저장소의 경로는 바뀌지 않습니다.

3. 실행과 확인
  HTTPS 정적 호스팅 또는 로컬 HTTP 서버로 실행하세요.
    python3 -m http.server 8765
  브라우저에서 서버 주소의 /sikjasil/을 엽니다. 독립 패키지는 압축을 푼 폴더의 루트를 엽니다.
  file:// 더블클릭 실행은 지원하지 않습니다. 대용량 귀신 base64 테스트 번들은 제거했습니다.
  메인 판권의 거꾸로 박힌 版 글자를 누르거나, 게임 주소로 직접 들어가 시작할 수 있습니다.
  방의 필수 게임을 모두 해결해야 다음 구간이 열립니다.
  철문 안 종이에 머리카락 엉킨 열쇠를 놓아야 지하실이 열립니다.
