# 독립 라디오 체험

정적 HTTP 서버에서 `/radio-device/`를 열면 응접실 → 다이얼 조작 → 수신 기록 순서로 진행합니다. 마우스·터치·휠·방향키를 지원합니다. 수신 미터가 정답 위치를 안내합니다.

기본 상태는 방송 음원 없이 파형을 표시하는 체험입니다. 실제 음원을 넣으려면 `assets/broadcast.mp3`를 추가하고 `index.html`의 `<body>`에 `data-broadcast-src="./assets/broadcast.mp3"`를 지정하세요. 음원이 없으면 안내 문구와 파형만 표시하며, 존재하지 않는 기본 음원 주소를 요청하지 않습니다.

`app.js`의 `TARGET_ANGLE`과 `SNAP_RANGE`로 정답 위치·허용 범위를 조정할 수 있습니다. 사건 지면의 라디오 장치와 이 독립 체험은 서로 다른 구성입니다.
